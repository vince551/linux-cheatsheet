# Visual Assets

The main README expects these four learning visuals:

- `linux-commands.jpg` — Linux command overview
- `how-linux-works.jpg` — Linux architecture overview
- `kali-tools.jpg` — Kali security tools reference
- `linux-learning.jpg` — beginner Linux learning map

Place the four supplied images in this directory with exactly those filenames. The README already references them in the Visual Learning Gallery.

## Recommended image practice

Keep images educational, legible and appropriately licensed. Prefer original artwork, public-domain assets, or images you have permission to redistribute.
