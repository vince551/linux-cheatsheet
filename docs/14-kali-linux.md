# 14 · Kali Linux

Kali is a Debian-based distribution for security testing, research and forensics. Learn the Linux and networking foundations first.

## Learning sequence
```text
Linux → Networking → Web basics → Security concepts → Authorized labs → Tooling → Defense
```

## Common categories
| Category | Example |
|---|---|
| Reconnaissance | Nmap |
| Packet analysis | Wireshark |
| Web testing | Burp Suite |
| Security frameworks | Metasploit |
| Forensics | Forensic utilities |

Start by reading each tool's official documentation and practice only in labs, CTFs or systems where you have permission.
