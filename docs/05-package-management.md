# 05 · Package Management

## Debian / Ubuntu / Kali
```bash
sudo apt update
sudo apt upgrade
apt search package
apt show package
sudo apt install package
sudo apt remove package
```

## Fedora
```bash
sudo dnf upgrade
sudo dnf install package
```

## Arch
```bash
sudo pacman -Syu
sudo pacman -S package
```

Always prefer official repositories or trusted package sources.
