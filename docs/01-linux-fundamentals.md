# 01 · Linux Fundamentals

## What is Linux?
Linux is an operating-system ecosystem built around the Linux kernel. A typical distribution combines the kernel with user-space tools, libraries, package management and applications.

## First commands
```bash
pwd
ls -lah
cd /path
whoami
id
uname -a
cat /etc/os-release
man ls
ls --help
```

## Shell model
```text
Terminal → Shell → Command → Kernel / system calls → Hardware or filesystem
```
