# 10 · Git & Development

```bash
git clone URL
cd repo
git status
git add .
git commit -m "message"
git pull
git push
```

## Branches
```bash
git switch -c feature/name
git switch main
git branch
git log --oneline --graph --decorate
```

## Useful developer tools
```bash
python3 --version
node --version
npm --version
make --version
```

Prefer project-specific package managers and documented setup instructions when working on existing projects.
